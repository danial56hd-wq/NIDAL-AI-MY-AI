## Overview

**My.AI** is a comprehensive, single-file scientific AI platform designed for:
- 📐 Mathematical calculations and visualization
- 🧪 Scientific research and analysis
- 🏗️ Engineering computations
- 📚 Educational support
- 🌍 Multi-language support (Arabic & English)

### Key Highlights

✨ **Zero Installation** - Open and run in your browser  
✨ **No Server Required** - Everything runs locally  
✨ **Bilingual** - Full Arabic (RTL) and English (LTR) support  
✨ **Feature-Rich** - 15+ integrated tools and calculators  
✨ **Privacy First** - All data stays on your device  
✨ **Open Source** - MIT Licensed

## 🎯 Features

### 🧮 Scientific Calculator
- **Basic Operations**: Addition, subtraction, multiplication, division, power
- **Advanced Functions**: Sin, Cos, Tan, Log, Ln, √, ∛, factorial
- **Modes**: DEG (Degrees) / RAD (Radians) conversion
- **Memory**: Store and recall calculations
- **History**: Track your calculation history

### 📐 Mathematical Editor
- **LaTeX Support**: Full KaTeX rendering engine
- **Real-time Preview**: See equations as you type
- **Symbol Panel**: 50+ scientific symbols at your fingertips
- **Equation Library**: Pre-built equations for quick reference
- **Export**: Copy equations in multiple formats

### 📊 Data Visualization
- **Interactive Graphs**: Plot functions and equations
- **3D Visualization**: Three.js powered 3D rendering
- **Plotly Charts**: Advanced charting capabilities
- **Customizable**: Colors, axes, labels, and more
- **Export**: Download charts as PNG/SVG

### 🗺️ Maps & Geolocation
- **Interactive Maps**: Leaflet.js based mapping
- **Location Search**: Search for any place
- **Current Location**: Get your GPS coordinates
- **Coordinates Display**: Latitude/Longitude precision
- **Tile Options**: Multiple map styles

### 🔄 Unit Converter
- **15+ Categories**: Length, mass, volume, temperature, speed, etc.
- **Instant Conversion**: Real-time conversion as you type
- **Common Units**: Metric, Imperial, and custom units
- **Precision**: Accurate to multiple decimal places

### 💬 AI Chat Interface
- **Message History**: Save and manage conversations
- **Multi-Provider**: Support for multiple AI providers
- **Attachments**: Upload and share files
- **Code Highlighting**: Beautiful code rendering
- **Export**: Download conversations as Markdown

### 🎤 Voice Features
- **Speech-to-Text**: Real-time voice input
- **Text-to-Speech**: Hear AI responses
- **Language Detection**: Auto-detect input language
- **Quality**: High-quality audio processing

### 📝 Markdown Support
- **Full Rendering**: Complete Markdown to HTML
- **Code Syntax**: Highlight.js for 100+ languages
- **Diagrams**: Mermaid support for flowcharts
- **Tables**: Beautiful table formatting
- **LaTeX**: Embedded mathematical expressions

### 🎨 Theme System
- **Dark Mode**: Easy on the eyes (default)
- **Light Mode**: Bright and clean
- **Persistent**: Your theme preference is saved
- **Smooth Transitions**: Beautiful theme switching

### 💾 Data Management
- **Local Storage**: Save sessions locally
- **Session Management**: Create, load, delete chats
- **Auto-Save**: Automatic session persistence

### 🌍 Internationalization

## 🚀 Installation & Usage

### Method 1: Direct Browser Open (Recommended)

1. **Download** the `NIDAL-AI-My.AI-Application.html` file
2. **Double-click** the file → Opens in your default browser
3. **Start using** immediately!

```bash
# No installation required!
```

### Method 2: Open with Browser

1. Right-click on `NIDAL-AI-My.AI-Application.html`
2. Select **"Open with"** → Choose your browser
3. Enjoy!

### Method 3: Development Setup

```bash
# Clone the repository
git clone https://github.com/nidalwatfa/NIDAL-AI.git
cd NIDAL-AI

# Install dependencies
cd frontend
npm install

# Start development server
npm start

# Build for production
npm run build
```

### System Requirements

| Component | Minimum | Recommended |
|-----------|---------|------------|
| **Browser** | Chrome 60+ / Firefox 55+ / Safari 12+ / Edge 79+ | Latest version |
| **RAM** | 512 MB | 2 GB+ |
| **Storage** | 100 MB | 500 MB |
| **Network** | Optional (mostly works offline) | Broadband for CDN resources |
| **OS** | Windows 7+ / macOS 10.12+ / Linux | Windows 10+ / macOS 10.15+ / Modern Linux |

## 📖 Features in Detail

### Calculator Usage
```
1. Click on the CALC tab
2. Use buttons or keyboard to input
3. Press = or Enter to calculate
4. Toggle DEG/RAD for angle mode
```

### Math Editor Usage
```
1. Click on the PREVIEW tab
2. Type LaTeX equations
3. Preview renders in real-time
4. Click symbols to insert them
```

### Plotting Data
```
1. Go to the 3D or GRAPH tab
2. Enter equation or data
3. Customize colors and axis labels
4. Click PLOT to visualize
5. Export as PNG when done
```

### Chat Interface
```
1. Type your question in the chat input
2. Attach files if needed
3. Press Enter or click Send
4. Use voice input with 🎤 button
5. Copy responses with 📋 button
```

### Maps
```
1. Navigate to the MAP tab
2. Search for a location or
3. Click "Use My Location" for GPS
4. View coordinates and nearby info
```

4. **Voice Input**: Browser must support Web Speech API

## 🆘 Troubleshooting

### Application Won't Load
```
✓ Clear browser cache (Ctrl+Shift+Delete)
✓ Try a different browser
✓ Check internet connection
✓ Disable browser extensions
```

### Calculator Not Working
```
✓ Refresh the page (F5)
✓ Check JavaScript is enabled
✓ Try in private/incognito mode
```

### Voice Input Failing
```
✓ Check microphone permissions
✓ Ensure HTTPS connection (required for voice)
✓ Test microphone in browser settings
```

### Settings Not Saving
```
✓ Check if LocalStorage is enabled
✓ Ensure you're not in private mode
✓ Clear browser cache
✓ Check storage quota
```
